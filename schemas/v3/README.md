# V3 Schemas

Versioned schemas for prospective V3 records live here.

Planned record types:

- contract metadata
- settlement metadata
- market BBO event
- collector-health event
- weather-publication event
- station-observation event
- shadow signal / decision
- execution record

Never store:

- IBKR account identifiers
- usernames
- authentication tokens/cookies
- bank information
- tax identifiers
- identity-document information
- exact residential addresses
